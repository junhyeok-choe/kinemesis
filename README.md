# kinemesis

> **Status: pre-alpha, planning only. No engine code exists yet.** Name confirmed by the maintainer on 2026-10-29: **kinemesis** (kinema + mimesis). Intended package names: distribution `kinemesis`, import `kinemesis`, CLI `kinemesis` (nothing is published to PyPI yet).

Kinemesis (κίνημα + μίμησις) — μια ανεξάρτητη μηχανή 2D κίνησης για αρθρωτές φιγούρες: καθαρή, ντετερμινιστική και ελεύθερη, ώστε κάθε στιγμή της κίνησης να μπορεί να υπολογιστεί, να ελεγχθεί και να αναπαραχθεί.

*(Draft Greek text, needs review by a native speaker. English: an independent 2D animation engine for articulated figures — clean, deterministic and free — so that every instant of motion can be computed, verified and reproduced.)*

## What this will be

A standalone, Python-native 2D animation engine: articulated figures and rigs, forward/inverse kinematics, keyframes and easing, deterministic evaluation at any time, headless rendering, a Python API and CLI, and a versioned, editable project format. Manim Community support is planned as an **optional, separate adapter**; the engine must never depend on Manim, a GUI, or an MCP server.

Name: *kinema* (κίνημα, movement; root of both "kinematics" and "cinema") + *mimesis* (μίμησις, imitation/representation).

Backronym (K·I·N·E·M·E·S·I·S): **K**eyframes · **I**nverse kinematics · **N**ode graph · **E**asing · **M**otion graphics · **E**valuation (deterministic) · **S**keletons · **I**nterchange · **S**cenes.

## Decisions approved so far

- **Licence:** GPL-3.0-or-later.
- **Compatibility scope:** upstream-equivalence claims cover native keyframe FK and tween only for M1–M2; container import at M3; upstream extensions deferred.
- **Python:** 3.14 target, core compatible with 3.12.
- **Oracle:** running upstream JS in an isolated no-network sandbox was approved and done once for the fixtures above.
